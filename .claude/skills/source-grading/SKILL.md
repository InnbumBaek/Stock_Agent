# 출처 등급

회의에서 위험한 것은 틀린 숫자가 아니라 **등급이 지워진 숫자**다. 등급이 없으면
누군가의 추측과 한국거래소 공식 통계가 같은 무게로 읽힌다.

**새 재료를 붙일 때는 어느 등급인지 먼저 정하고** 그 절의 출처 줄에 넣는다.

## 다섯 등급

| 등급 | 무엇 | 근거로 삼아도 되는가 |
|---|---|---|
| **1차** | KRX · DART · 한국은행 ECOS · FRED · KIS | 된다 |
| **참고** | 뉴스 헤드라인 · 심리지표 | "이런 이야기가 돈다"까지만 |
| **방법론** | 논문 | 계산 **규칙**의 출처. 시세 출처가 아니다 |
| **사내** | `exit_plan.csv` · `watchlist.csv` 등 우리가 넣은 값 | 우리 값임을 밝히고 |
| **해석** | 데스크가 재료를 읽고 쓴 문장 | 해석으로서만 |

## 섞지 마라

한 문장에 두 등급의 재료가 들어가면 **낮은 쪽**이 그 문장의 등급이다. KRX
종가와 뉴스 헤드라인을 섞어 쓴 문장은 `참고` 다.

## 해석은 승격되지 않는다

이것이 가장 중요한 규칙이고 가장 자주 깨진다.

에이전트가 1차 자료를 읽고 쓴 문장은 1차 자료가 **아니다.** 읽은 재료가
KRX 였다는 사실이 그 해석을 KRX 로 만들지 않는다.

```
KRX 일별매매정보          →  1차
그것을 읽고 계산한 회전율   →  1차 (결정적 계산, 원장이 냄)
"회전율이 낮아 처분이 어렵다" →  해석  ← 여기서 등급이 바뀐다
```

승격 경로를 아예 없애 두지 않으면, 몇 단계를 거치는 사이에 누군가의 추측이
공식 통계의 얼굴로 회의에 올라온다. `agents/envelope.py` 의 `promote()` 가
`해석` 을 어느 등급으로도 올려 주지 않는다.

올리고 싶으면 **1차 자료를 직접 인용하는 새 문장**을 쓴다. 그것은 승격이
아니라 다른 주장이다.

## 판정 순서

1. 이 값이 공식 API 응답 **그대로**인가 → `1차`
2. 공식 값에서 **결정적 계산**만 거쳤는가 → `1차` (계산 규칙의 출처는 `방법론`)
3. 우리가 파일에 넣은 값인가 → `사내`
4. 논문에서 온 **규칙**인가 → `방법론`
5. 뉴스·심리지표인가 → `참고`
6. **사람이나 에이전트가 읽고 쓴 문장인가 → `해석`**

6번에서 걸리면 앞의 것이 무엇이었든 `해석` 이다.

## 검사

`agents/gates.py` 의 게이트 ② 가 등급 없는 주장과 `해석` 의 승격 흔적을
반려한다.
