# 게이트 ①~⑦

`selftest` 는 **코드**가 성립하는지 본다. 게이트는 **에이전트가 쓴 문장**이
성립하는지 본다. 둘은 다른 층이고, 앞의 것이 아무리 촘촘해도 뒤의 것을 대신하지
못한다.

측정 함수가 12.4 를 정확히 계산해도, 그 값에 "매도 검토" 라는 말이 붙어
회의자료로 나가면 이 시스템은 실패한 것이다.

## 통과 아니면 반려다

**"대체로 지켜졌다"는 판정이 없다.**

반려된 절은 회의자료에 빈칸이 아니라 **'반려됨 — 사유'** 로 보인다. 빈칸은
아무도 묻지 않지만 '반려됨'은 반드시 묻게 된다. 조용히 통과시키는 것이 가장
위험하다.

## 일곱

| | 무엇을 보는가 | 걸리면 |
|---|---|---|
| ① 판정 어휘 | 점수·목표주가·매수/매도 어휘가 산문에 있는가 | 문장 삭제 후 반려 |
| ② 출처 등급 | 모든 주장에 등급이 있는가 · `해석` 이 승격되지 않았는가 | 등급 없는 주장 차단 |
| ③ 재현 | 인용 논문의 상태가 무엇인가 | `retired` · '방향 반대' → 반려 |
| ④ 논문 실재 | 장부에 실재하는가 · `limits` 가 비어 있지 않은가 | 지어낸 인용 차단 |
| ⑤ 신선도 | `asof` · `stale_days` 가 3영업일을 넘지 않는가 | 값 대신 '데이터 없음' |
| ⑥ 유출 검사 | 키·인증 URL·실명이 남았는가 | **발행 전체 중단** |
| ⑦ 4-eyes | 리스크와 준법감시 양쪽이 승인했는가 | 해당 절 제외 |

## ③ 과 ④ 는 다른 것을 본다

자주 혼동된다.

- **③ 은 상태를 본다.** 막는 것은 `retired` 와 '방향 반대'뿐. `unverified` 는
  통과하되 '미검증' 표시가 함께 나간다. 봉투가 적은 상태와 장부가 어긋나도
  반려한다 — 오래된 상태를 물고 온 것이기 때문이다.
- **④ 는 실재를 본다.** 장부에 없는 논문 키를 막는다. **지어낸 인용**을 잡는
  관문이다. `limits` 가 비어 있는지도 여기서 본다.

## ⑥ 은 절이 아니라 발행 전체를 멈춘다

유출은 되돌릴 수 없다. 다른 절이 멀쩡한지는 이 판단에 영향을 주지 않는다.

`requests` 예외에는 호출 URL 이 통째로 들어가고 DART 는 인증키를 쿼리
파라미터로 보낸다. 데스크가 오류 문구를 그대로 봉투에 옮겨 담으면 그 키가
회의자료까지 간다. 사람에게 보이는 예외는 전부 `scrub()` 을 통과시킨다.

## ⑦ 자기 검토는 검토가 아니다

같은 데스크가 스스로를 승인할 수 없다. `reviewed_by` 에 자기 이름이 있으면
반려다.

## 하나 걸려도 일곱을 다 본다

첫 반려에서 멈추면 두 번째 문제를 볼 때까지 왕복이 는다. `run()` 은 일곱을 다
돌리고 반려 사유를 **전부** 모아서 낸다.

## 게이트를 사람 판단으로 통과시키지 마라

게이트는 코드다. 준법감시역이 하는 일은 그 결과를 **집행**하는 것이지 다시
판단하는 것이 아니다. "이번은 사정이 있으니"가 한 번 통과하면 그 관문은 그날로
없어진다.

관문이 잘못됐다고 생각되면 그 판단은 회의에서 하고, 고치는 것은 `gates.py` 다.

## 반려는 스코어카드로 간다

무엇이 왜 반려됐는지가 쌓인다. **반려가 잦은 지점이 곧 스킬 문서를 고쳐야 할
곳이다** — 프롬프트가 아니라. 그리고 그것을 고치는 것은 사람이다.

## 돌리기

```bash
python agents/gates.py --check 봉투.json    # 통과하면 0, 반려면 1
python agents/gates.py --selftest
```
