# 포트폴리오 — 메자닌 회수 판단 시스템

`메자닌_회수판단시스템_포트폴리오.pptx` — 19장. 코스닥벤처·메자닌 운용역 지원용.

## 이 덱이 하는 일

`docs/agentization/` 의 계획안이 "앞으로 무엇을 만들 것인가" 라면, 이 덱은
**"이미 무엇을 만들었고 그게 왜 메자닌 실무 역량인가"** 를 보여준다.

저장소를 다시 읽어 보면 이 프로젝트는 처음부터 메자닌 도구였다. 이름만
"주가 모니터링" 이었을 뿐이다.

| 코드에 이미 있는 것 | 메자닌 실무에서 뜻하는 것 |
|---|---|
| `refix_scenario(cb_amount, price, floor_price)` | 리픽싱 — 주가 하락 시 전환가 조정과 희석 가속 |
| `fully_diluted_ownership(..., cb_potential, bw_potential, option_pool)` | 완전희석 지분 — 전환 후 기준 지분율 |
| `adjust_audit()` 의 희석/권리락 판별 | CB 전환은 권리락이 아니다 — 수정주가를 조정하면 안 된다 |
| `LOCKUP_MONTHS = 6` | 벤처금융 보호예수 (추정 등급으로 표시) |
| 처분 소요일수 (평균 · 중앙값) | 팔 수 있는가 — 코스닥 소형주는 평균이 낙관적이다 |
| 매도 규칙 4종 시뮬레이션 | 어떻게 팔 것인가 |
| `dilution` 공시 분류 | 전환사채 · BW · EB · 전환가액 · 행사가액 |

## 가장 강한 한 장

**§7 희석은 권리락이 아니다.**

무상증자는 주식수 ×2 · 주가 ÷2 이므로 수정주가를 조정한다. CB 전환은 주식수만
늘고 주가는 시장이 정하므로 **조정하면 안 된다.** 자동 수정주가 라이브러리는
이 둘을 구분하지 못해서, 전환 이전 구간 수익률이 조용히 틀어진다.

이 구분이 `adjust_audit()` 에 구현돼 있고 `selftest` 가 매번 검사한다.
판별이 안 되면 조정하지도 지우지도 않고 '확인 필요' 로 남긴다.

## 제도 수치에 대하여

리픽싱 최저한도(최초 전환가액의 70%), 상향조정 의무, 코스닥벤처펀드 편입요건
(신주 15% · 합계 50%), 공모주 우선배정(2026-01-01 이후 30%), 소득공제 한도 축소는
금융위원회·금융투자협회 공개자료 기준이다.

**제도는 자주 바뀐다.** 실제 운용에 쓰기 전에 현행 규정 원문으로 재확인해야 하며,
이 저장소의 원칙대로 확인한 날짜와 함께 적어야 한다.
