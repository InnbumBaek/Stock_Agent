# v2 계획안 — 살아있는 리서치 데스크

`Stock_Agent_v2_계획안.pptx` (19장). v1 이 조직도였다면 v2 는 흐름이다.

## v1 에서 무엇이 바뀌나

| 항목 | v1 | v2 |
|---|---|---|
| 논문 | 채택본 12편 고정 · 손으로 고른 목록 | 매주 수확 → 재현 검사 → 통과분만 채택 · 반감기 지나면 은퇴 |
| 근거 | 논문을 인용한다 | 논문을 **우리 원장에서 재현해 보고** 인용한다 |
| 에이전트 | 상설 8데스크 · 매일 전수 실행 | 상설 3 + 이벤트 소집 N · 변동분만 실행 |
| 수명 | 계속 떠 있다 | spawn → 봉투 → dissolve · 무상태 |
| 게이트 | 6개 | 7개 — 재현 관문 추가 |

## 핵심 1 — 재현 관문

채택본 12편은 전부 미국 표본 논문이다. **코스닥에서 성립하는지 아무도 확인한 적이 없다.**

논문에서 방향 있는 한 문장을 뽑아 → `ki.sqlite` 일봉으로 그 팩터를 계산 →
코스닥 전종목 분위 스프레드의 부호가 논문과 같은지 대조 → **재현된 것만 채택**.

판정은 `재현됨 / 방향 반대 / 판정 불가` 셋 중 하나이고, 실패도 지우지 않고 남긴다.
남겨 두어야 다음 사람이 같은 논문을 다시 주워 오지 않는다.

## 핵심 2 — 채택은 상태이지 영구 자격이 아니다

`.papers.json` 을 목록에서 **append-only 원장**(`ki.papers/2`)으로 바꾼다.

- 반감기 180영업일 → 재현 재검
- 1회 실패 → `warned` (인용은 되지만 경고가 함께 나간다)
- 연속 2회 실패 → `retired` (인용 차단)
- 은퇴본도 지우지 않는다 — 재수확 시 걸러내는 데 쓴다

## 핵심 3 — 이벤트 소집

공시 1건 = 인스턴스 1개. 봉투 내면 소멸. 무상태라 같은 입력 → 같은 봉투이고,
그래서 리플레이가 된다. 85종목 × 4데스크 전수(340회/일) 대신 그날 실제 변동분만.

## 지킨 것

원칙은 v1 과 같다 — 재기만 하고 판단하지 않는다 · 원장에는 사실만 · 없는 값을
만들지 않는다 · 등급을 섞지 않는다 · 키는 저장소 밖.

벽(정보교류차단)도 그대로다. **인스턴스가 1개든 400개든 쓰기 도구를 받는
인스턴스는 없다.** 에이전트 산출은 여전히 등급 '해석' 이며 1차로 승격되지 않는다.

## 자료 재생성

```bash
python docs/agentization/v2/sprites/sprites.py   # 픽셀 스프라이트 → PNG
npm install pptxgenjs
node docs/agentization/v2/build_deck.js "Stock_Agent_v2_계획안.pptx"
```

스프라이트는 문자 그리드를 PIL 로 구워 nearest-neighbour 확대한 것이다.
외부 이미지·CDN 을 쓰지 않는다.
