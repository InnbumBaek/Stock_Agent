# agents/ — 판단층

측정층(`stock-monitor/ki_monitor.py`)은 **재기만 한다.** 이 층은 그것을 읽어
문장으로 만든다. 그리고 둘 사이에 관문을 둔다.

문장은 숫자와 달리 조용히 틀린다. "처분에 12영업일" 이라는 말은 그 자체로는
근거의 등급도, 언제 잰 값인지도, 그 방법이 무엇을 주장하지 않는지도 담지
않는다. 회의에서 위험한 것은 틀린 숫자가 아니라 **등급이 지워진 숫자**다.

`ki_monitor.py` 는 열지 않는다. CRLF 파일이라 편집 도구가 줄바꿈을 바꾸면 파일
전체가 diff 에 잡히고 실제 변경이 그 안에 묻힌다. 감싸기만 한다.

```
envelope.py       모든 주장이 입는 형식 (측정값 + 등급 + 가정 + 한계)   16
papers.py         논문 장부 ki.papers/2 — 네 상태 · append-only        19
replication.py    재현 러너. 결정적이다 — LLM 을 쓰지 않는다            16
gates.py          게이트 ①~⑦. 통과 아니면 반려다                      20
ki_ledger_mcp.py  원장을 읽는 MCP 서버. 쓰기 도구가 없다               22
                                                             합계  93
```

## 검증

```bash
python agents/selftest.py          # 93개. 키·네트워크·원장 없이 돈다
python agents/gates.py --selftest  # 모듈 하나만 돌릴 수도 있다
```

측정층의 128개와 나란히 돌린다. 검증이 두 곳으로 갈라지면 한쪽은 곧 안 돌게
된다.

## 네 가지 결정

### 1. 재현 임계는 t ≥ 3.0 이다

2.0 이 아니다. 2.0 은 검정을 **한 번** 할 때의 값이고, 주 1회 사이클이면 연
150회쯤 된다. 그때 2.0 은 아무 효과 없는 팩터를 해마다 7~8개 통과시킨다. 그
팩터들은 "논문 근거 있음" 딱지를 달고 회의에 올라간다 — 이 시스템이 막으려고
만들어진 바로 그 실패다.

근거는 Harvey·Liu·Zhu (2016) RFS 29(1) 5-68 이고, 그 논문은 `.papers.json` 의
`method_papers` 에 **한계와 함께** 들어 있다. 3.0 은 보정 방식과 가정한 검정
횟수에 따라 달라지는 값이지 자연상수가 아니다.

대가가 있다. 통과가 드물어진다. 그것이 의도다 — 이 관문은 통과시키려고 만든
것이 아니라 가려내려고 만든 것이다.

### 2. 기존 12편은 `unverified` 로 들어갔다

`adopted` 가 아니다. 사람이 읽고 고른 좋은 논문들이지만, 우리 원장에 대고
계산해 본 적은 없다. 재현 관문을 만들면서 기존 항목만 통과한 것으로 쳐 주면
그 관문은 **처음부터 빈 관문**이다.

`unverified` 는 인용을 막지 않는다. '미검증' 표시를 달고 나간다. 주 1회
사이클로 돌리면 어느 시점에나 아직 재현을 돌리지 못한 논문이 남고, 그것을 전부
막으면 관문이 아니라 정지 버튼이 된다.

인용이 실제로 막히는 것은 `retired` 뿐이다.

### 3. MCP 서버의 권한은 프롬프트가 아니라 도구 목록이 정한다

에이전트에게 "원장에 쓰지 마라"고 부탁하지 않는다. 쓰는 도구를 주지 않는다.
프롬프트로 건 금지는 프롬프트가 길어지면 희미해지고 모형이 바뀌면 같이 바뀐다.

세 겹이다 — ① 쓰기 도구가 없다 ② 연결이 `mode=ro` 다 ③ 생 SQL 을 받지 않는다.

### 4. '해석' 은 어떤 등급으로도 승격되지 않는다

CLAUDE.md 규칙 4 의 네 등급에 다섯 번째를 더했다. 앞의 넷은 재료의 등급이고,
'해석' 은 **데스크가 만든 문장**의 등급이다.

에이전트가 1차 자료를 읽고 쓴 문장은 1차 자료가 아니다. 읽은 재료가 KRX
였다는 사실이 그 해석을 KRX 로 만들지 않는다. 승격 경로를 아예 없애 두지
않으면, 몇 단계를 거치는 사이에 누군가의 추측이 공식 통계의 얼굴로 회의에
올라온다.

## MCP 서버 쓰기

`.claude/settings.json` 에 `ki-ledger` 로 등록돼 있다. 원장이 없어도 서버는
서고, 도구를 부르면 "`ingest` 를 먼저 하십시오" 라고 답한다 — 세션마다 죽어
있는 서버보다 사유를 말하는 서버가 쓸모 있다.


  맞다는 것까지만 확인했다. 12편이 코스닥에서 실제로 어떻게 나오는지는 아직
  모른다. `ki.sqlite` 가 있는 곳에서 돌려야 한다.
- `triggers.py` — 트리거 스캐너·소집 (Phase 2)
- `.claude/agents/` 데스크 9개 정의, `.claude/skills/` 규칙 5종 (Phase 2)
- `method_papers` 두 편의 **Crossref 재대조.** 서지는 세 곳에서 일치를 확인했지만,
  이 환경의 이그레스 정책이 Crossref 를 막아 프로젝트 규율대로의 재대조를 하지
  못했다. 네트워크가 열린 곳에서 `docs/fetch_papers.py` 로 다시 볼 것.
