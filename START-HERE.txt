==========================================================
  주가 모니터링 — 더블클릭할 것은 둘뿐입니다
==========================================================

  ※ 먼저 zip 을 폴더에 **푸십시오.**
    압축 프로그램 안에서 .cmd 를 바로 더블클릭하면, 그 파일 하나만
    임시 폴더에 풀려 실행됩니다. 옆에 있어야 할 폴더가 없어서 그대로
    멈춥니다. (풀지 않고 누르면 그 사실을 알려주고 멈춥니다)

  ※ 더블클릭했는데 **아무 반응이 없다면** — 윈도우가 막은 것입니다.
    (문법 오류라면 창은 뜹니다. 창 자체가 안 뜨는 것은 차단입니다)

    먼저 RUN_ALL.bat 을 눌러 보십시오. 같은 것을 부르는데 연결이 다릅니다.
    .cmd 만 막히는 컴퓨터에서는 이쪽이 열립니다.

    그래도 안 뜨면, 시작 → "PowerShell" 검색 → 열고 아래 한 줄을 붙여넣고
    Enter. 폴더를 찾아 차단을 풀고 실행까지 합니다. 경로는 몰라도 됩니다.

      $p=Get-ChildItem $HOME -Recurse -Filter RUN_ALL.cmd -EA 0 | Select -First 1; Get-ChildItem $p.Directory -Recurse | Unblock-File; Start-Process cmd -ArgumentList '/k',$p.FullName

    이것까지 안 되면 회사 정책이 스크립트를 막는 것입니다. 그 화면의 문구를
    그대로 알려주시면 그때는 다른 길로 갑니다.


  RUN_ALL.cmd         ★ 이것 하나면 끝납니다.

                      환경 점검 → API 진단 → 원장 → 논문 → 리포트
                      회의 자료 HTML 을 만들어 열어 줍니다.

                      중간에 죽어도 다시 돌리면 이어서 갑니다.
                      원장이 이미 있으면 40분짜리 적재를 다시 안 합니다.

                      RUN_ALL.cmd auto   묻지 않고 끝까지

  RUN_ALL.bat         RUN_ALL.cmd 가 안 열릴 때 대신 누르십시오 (같은 것입니다)

  SCHEDULE.cmd        평일 자동 실행을 등록·해제합니다.

                      → 07:30  논문 수확 · 채택 (하루 최대 1편)
                      → 08:50  아침 리포트
                      → 16:10  장 마감 시세 적재

                      ※ RUN_ALL 을 한 번 끝낸 뒤에 등록하십시오.
                        원장이 있어야 리포트가 나옵니다.
                      ※ 폴더를 옮기셔도 됩니다. RUN_ALL 이 다음에 돌 때
                        어긋난 경로를 알아서 다시 등록합니다.


  회의 자료는 stock-monitor\out\ 에 HTML 로 쌓입니다.
  기록은 logs\ 에 남습니다.

  키는 이 폴더가 아니라 다음 자리에 둡니다 (저장소 밖):
      %USERPROFILE%\Stock-Agent-keys\.env
  쓰시던 .env 가 컴퓨터 어딘가에 있으면 RUN_ALL 이 찾아서 옮깁니다.
